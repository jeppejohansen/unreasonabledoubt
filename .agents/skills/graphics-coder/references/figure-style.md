# Figure style for new posts

Use a clean white background, readable sans-serif text, restrained grid lines, and direct labels where practical. Prefer a focused plot over a crowded multi-panel figure. Label quantities and units; explain abbreviations in the caption or text.

Default semantic colors for new figures:

| Meaning | Color | Hex |
| --- | --- | --- |
| Baseline or primary path | Blue | `#0072B2` |
| Alternative or policy change | Vermilion | `#D55E00` |
| Additional scenario | Bluish green | `#009E73` |
| Fourth scenario | Reddish purple | `#CC79A7` |
| Reference or uncertainty | Gray | `#777777` |

Do not use color alone to distinguish important series. Pair it with solid, dashed, or dotted lines, or clear direct labels. Keep the same meaning-color pairing across related figures in a post. Use 200 DPI PNG as a sensible default for blog graphics; adjust dimensions for the actual publication width. Avoid placing a long title inside the image when the post supplies a caption.

Before export, check that no label, legend, or annotation covers data. View the saved PNG rather than relying only on the plotting code.
